# Test Layout

This repository keeps tests grouped by feature and by test level.

- `tests/parser/fixtures/`: sample inputs for parser tests
- `tests/parser/helpers/`: fixture builders and parser test helpers
- `tests/parser/integration/`: end-to-end parser chain tests
- `tests/parser/integration/test_file_structuring_pipeline.py`: structuring pipeline tests using fake LLM responses and fallback checks
- `tests/parser/integration/test_file_parser_agent_structuring.py`: file parser agent test that verifies structuring output overrides baseline when LLM is available
- `tests/parser/integration/test_llm_utils.py`: `.env` loading and LLM adapter tests
- `tests/parser/manual/`: interactive parser debug scripts for local file input
- `tests/generate/integration/`: generate pipeline and generate agent integration tests
- `tests/generate/manual/`: interactive generate runners that call parser first and then generate
- `tests/logs/parser/integration/`: runtime logs and output artifacts generated by parser integration tests
- `tests/logs/parser/manual/`: runtime logs and artifacts generated by manual parser runs

Useful entry points:

- `tests/parser/integration/test_user_input_to_parser_output.py`: pytest-style integration test
- `tests/parser/integration/run_user_input_to_parser_output.py`: direct runner that prints the actual log and artifact paths
- `tests/parser/integration/test_supported_asset_parsers.py`: multi-file integration test for `txt/pdf/pptx/docx`
- `tests/parser/integration/run_supported_asset_parsers.py`: direct runner for the multi-file integration chain
- `tests/parser/manual/run_local_file_parser.py`: interactive script for manually entering file type and local file path
- `tests/parser/manual/run_local_file_parser_agent.py`: interactive script that uses the real parser agent entry, loads `.env`, and shows baseline vs final structured output
- `tests/generate/integration/test_generate_pipeline.py`: generate pipeline tests using fake LLM section outputs and rule fallback checks
- `tests/generate/integration/test_generate_agent.py`: generate agent test that verifies pipeline output is packaged into `GenerateOutput`
- `tests/generate/manual/run_local_generate_agent.py`: interactive end-to-end runner for local files -> parser -> generate with artifact/log output

When a new feature gets tests, follow the same pattern:

1. Add fixtures under `tests/<feature>/fixtures/`
2. Add tests under `tests/<feature>/<level>/`
3. Add runtime logs or output artifacts under `tests/logs/<feature>/<level>/`
