# Skill: Example

## 适用场景

- 学生问“举个例子”“例如什么”“X 有哪些例子”
- 需要用具体实例帮助理解抽象概念
- 课程内容偏理论，必须补充案例

## 推荐工具

- `内容获取工具`：找课程里已有的例子
- `实例筛选工具`：筛出和问题最相关的案例
- `知识匹配工具`：对齐适合举例的知识点

## 回答策略

1. 先说概念。
2. 再给 1 个最贴近课程的核心例子。
3. 说明例子和概念的对应关系。
4. 必要时补充 1 到 2 个不同场景的例子。

## 禁止行为

- 不要只给例子不解释
- 不要给超纲例子
- 不要一次堆太多例子
- 不要离开课程材料硬编

## 输入要求

- `question`
- `structured_content`
- `current_section_id` / `current_page`

## 输出要求

- `answer`
- `references`
- `matched_knowledge_points`
- `suggested_questions`
