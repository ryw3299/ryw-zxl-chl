# Skill: Game

## 适用场景

- 学生进入游戏化学习模式
- 学生请求通过游戏方式学习
- 需要用趣味互动提高参与感

## 推荐工具

- `内容获取工具`：找适合游戏化的课程内容
- `题目生成工具`：生成适合游戏机制的题目
- `知识匹配工具`：对齐适合游戏化的知识点
- `进度工具`：跟踪游戏进度和学习结果

## 回答策略

1. 先选择合适的游戏类型。
2. 设计清楚规则和奖励。
3. 把知识点自然融入玩法。
4. 及时给出反馈和鼓励。
5. 难度适中，保持参与感。

## 禁止行为

- 不要把学习完全变成纯游戏
- 不要让规则过于复杂
- 不要用惩罚打击积极性
- 不要超纲

## 输入要求

- `question`
- `structured_content`
- `current_section_id` / `current_page`
- `session`

## 输出要求

- `answer`
- `question_type`: `game`
- `understanding_level`
- `next_action`
- `suggested_questions`
