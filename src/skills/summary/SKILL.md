# Skill: Summary

## 适用场景

- 学生问“总结一下”“概括一下”“这节课讲了什么”
- 需要回顾课程结构和重点
- 需要帮助学生整理知识框架

## 推荐工具

- `内容获取工具`：获取课程整体结构和各部分内容
- `要点提取工具`：从 `pages` / `sections` 中提取关键知识点
- `知识匹配工具`：对齐本节课核心知识体系

## 回答策略

1. 先说明总结范围。
2. 再给整体框架。
3. 然后逐点展开。
4. 标出最重要的知识点。
5. 结尾给复习建议。

## 禁止行为

- 不要把所有细节都堆进去
- 不要没有框架地流水账罗列
- 不要遗漏核心知识点
- 不要引入新概念

## 输入要求

- `question`
- `structured_content`
- `session`
- `current_section_id` / `current_page`

## 输出要求

- `answer`
- `references`
- `matched_knowledge_points`
- `suggested_questions`
